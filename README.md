# HoK Helper 安装包发布

此仓库仅提供 Android 安装包、更新说明及软件更新清单，不包含应用源码或用户战绩、昵称、截图。应用源码在独立私有仓库维护。

当前版本：**0.2.6 测试版**。本版仅新增“更多 → 连接电脑”及局域网战绩同步。

[下载 0.2.6 安装包](https://github.com/Michael37-tech/HoK-Helper-Releases/releases/tag/v0.2.6)

需要 Android 14 及以上。直接覆盖安装，无需卸载；建议先备份。已有 0.2.3 及以上版本可通过“更多 → 软件更新”检查，下载并确认安装。自动检查每天至多一次，非计费 Wi-Fi 下下载，记录、识别及复测期间暂停。安装前校验摘要、包名、版本与签名。

连接电脑需要另行运行电脑版建模工作台：电脑复制配对信息，手机粘贴并开启“自动同步战绩”，双方处于可互通的同一局域网。默认关闭。开启后仅向用户配对的电脑同步必要结构化战绩；手机是主数据源，截图、昵称和异常档案留在手机。本版不包含模型预测、自动 BP 识别或云服务。

`update.json` 是应用使用的版本清单。GitHub 自动生成的 Source code 压缩包仅包含本仓库发布资料，不是应用源代码。
