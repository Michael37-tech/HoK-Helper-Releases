# HoK Helper 测试版发布

手机版当前版本 **0.2.8**；Windows 工作台仍为 **0.2.7**。本仓库仅分发安装包、摘要及更新清单，应用源码保持私有。

[下载手机版 0.2.8](https://github.com/Michael37-tech/HoK-Helper-Releases/releases/tag/v0.2.8)

版本 0.2.8 / versionCode 18，Android 14 及以上。沿用原个人测试签名，可覆盖安装；建议更新前备份。Windows 工作台未改动，继续使用 0.2.7。

- 新增默认关闭的“随王者荣耀启动”：允许使用情况访问、悬浮窗和通知后，监听游戏进入前台，确认屏幕共享后自动检测结算。每个新截图会话仍需系统授权。
- 切出游戏隐藏入口并暂停采集，返回有效会话后恢复；取消授权或手动停止后本次不再打扰。重启解锁后恢复已开启的监听，强制停止后需重新打开助手。
- 修复普通自动检测时反复隐藏悬浮窗的闪烁，仅在实际保存干净截图时短暂避让并复核新画面。
- 支持上、下、左、右四边收纳及位置记忆；点击箭头或向内拖动均可展开，兼容旧位置设置和横竖屏。
- 原有手动记录继续独立使用；沿用现有结算识别、截图后台任务和电脑连接协议。

全屏共享时应避免展开面板挡住结算关键文字，推荐单应用共享。部分手机需另行允许自启动、后台运行和后台弹窗；真实三星手机的后台策略、游戏动画及单应用共享效果仍需体验。使用个人测试签名，供个人测试，不提供云服务。
