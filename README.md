# HoK Helper 测试版发布

当前版本 **0.2.7**。本仓库仅提供 Android APK、Windows 工作台 ZIP、摘要与更新清单，应用源码保持私有。

[下载 0.2.7](https://github.com/Michael37-tech/HoK-Helper-Releases/releases/tag/v0.2.7)

版本 0.2.7 / versionCode 17，Android 14 及以上，沿用已有签名，可覆盖安装。新增 Windows 个人测试建模工作台（完整 ZIP 解压后运行 exe，保留 _internal）。建议更新前备份。

- 手机采用战绩、统计、设置导航，增加搜索与组合筛选、独立战绩详情、分步核对及重复记录处理。
- 优化悬浮窗侧边收纳、拖动和截图避让，修复冷却提示；整理英雄姓名识别、截图后台任务及备份恢复流程。
- 电脑接收局域网 HTTPS 战绩只读副本，提供统计、训练评估、英雄池和完整／不完整阵容手动试算。
- 同步重试、解绑竞争与副本提交失败保持状态一致；强化真实对局身份、独立评估累计、英雄字形及元流之子形态区分，迁移旧模型评估依据。

手机是主数据源，截图、昵称和异常档案不传输到电脑。连接电脑、软件更新、备份与开发者选项位于手机「设置」。已有 0.2.3 及以上可通过软件更新获取 APK。Windows 数据保存在本机，不提供云服务；自动 BP 识别后续接入。

Android 123 项单元测试、桌面 45 项测试通过；Lint 0 错误、55 条警告。模拟器覆盖安装和交互、Windows 打包启动及合成数据训练已验证，详细边界见私有源码发布报告。真实手机长期后台、游戏全屏捕获观感和真实预测效果仍待验证。使用开发签名，供个人测试。

`update.json` 供手机版检查更新；GitHub 自动生成的 Source code 仅为分发资料。
